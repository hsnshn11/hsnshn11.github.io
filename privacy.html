Privacy Policy (English summary)

Prizma Muzik Panel is a private tool used by the Prizma Muzik label to manage its own social media accounts. It does not create accounts for third parties, does not collect visitor analytics and uses no advertising networks.

Data processed: OAuth access and refresh tokens; account identity (display name, username, avatar, follower/subscriber counts); video and post lists with basic statistics; comment text and the commenter's display name; and media files selected by the operator for publishing.

Storage: all data is stored only on the operator's own computer, in a local file (data/db.json) and a local media folder. The Panel is not hosted on a cloud server, uses no external database, and never sells, rents or transfers data to third parties. The only outbound traffic is to the official API endpoints of the connected platforms.

Retention and deletion: data is kept only while an account remains connected. Choosing "Disconnect" in the Panel deletes that account's tokens and cached profile/statistics from the local file; deleting the local data file removes everything. Access can also be revoked at any time from the platform's own security settings.

Sharing: no analytics, advertising or tracking services receive any data. When AI-assisted text suggestions are used, only the operator's own draft title/description text is sent to the provider - never tokens or audience data.

The Panel is not directed to children under 13. Contact: hsnshn2011@gmail.com
